비전공자 게임 프로그래밍, 첫 3개월에 확인할 것

취업 · 2026.10.27 · 6분 분량 · SBS아카데미게임학원 노원점

게임 프로그래밍을 처음 시작하는 비전공자는 “수학을 잘해야 하나요?”, “너무 늦은 건 아닐까요?”를 가장 많이 걱정합니다. 처음 3개월에 무엇을 해야 하는지만 분명하면, 생각보다 많은 분들이 첫 게임을 완성합니다.

1개월 차: 코드 읽는 법에 익숙해지기

변수, 조건문, 반복문, 함수처럼 모든 프로그래밍의 기본이 되는 개념을 C#으로 익힙니다. 이 시기의 목표는 외우는 것이 아니라, 남이 쓴 짧은 코드를 읽고 무슨 일이 일어나는지 설명할 수 있는 것입니다.

2개월 차: 엔진 위에서 움직여 보기

유니티 같은 게임 엔진에서 캐릭터를 움직이고, 점프하고, 충돌을 처리해 봅니다. 화면에서 내가 쓴 코드가 바로 움직이는 경험이 공부를 이어가는 가장 큰 동력이 됩니다.

3개월 차: 작은 게임 하나 끝까지 만들기

시작 화면, 플레이, 게임 오버까지 갖춘 작은 게임을 하나 완성합니다. 규모보다 ‘끝까지 만들었다’는 경험이 중요합니다. 이 결과물이 이후 포트폴리오의 첫 페이지가 됩니다.

첫 3개월에 남겨야 할 것

  • 직접 만든 플레이 가능한 미니 게임 1개
  • 막혔던 문제와 해결 과정을 적은 기록
  • 다음에 만들고 싶은 게임의 간단한 기획
노원점에서는 C# 기초부터 유니티·언리얼까지 단계별로 배우고, 팀프로젝트로 기획·아트 수강생과 함께 게임을 만드는 경험까지 이어갑니다.
